## Remaining human steps

1. Record and upload the working three-to-four-minute demo. Include a real query/tool trace and repair replay. Identify saved reports or shortened waits if used.
2. Open the public repository and video in an incognito window to confirm judges can access them.
3. Register or confirm registration on WeMakeDevs, select Track 01 and submit the repository and video links before the deadline.
4. Use the local-setup option if no hosted service is deployed. Do not paste localhost as a public deployment.

## Before recording

Run python preflight.py. Show the task app first, then the actual current run graph. The model calls validated Cypher tools; it does not generate arbitrary Cypher. A passing repair verifies the retained case, not every possible behavior.
